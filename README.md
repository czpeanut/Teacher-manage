# Teacher-Manage｜講師授課進度管理與自動板書備課 PDF 系統

依據各講師與班級的授課進度及課後回報狀況，自動計算下一堂建議難度係數（`1.0 ~ 5.0`），並自動組裝、排程與產出 **A4 直式黑白印刷最佳化板書備課 PDF**。

## 核心功能

- **講師備課工作台（`/instructor`）**
  - 檢視負責班級進度、當前難度係數與管理員教學指示。
  - 選擇單元與授課時長（2 小時 / 3 小時 / 1.5 小時），系統依難度自動選頁與排定 `[HH:MM-HH:MM]` 時段及中場休息。
  - 瀏覽器內即時預覽 A4 板書，並支援自由勾選微調後一鍵編譯下載真實 PDF。
  - **課後回報與動態評分**：填寫四維表現（理解度、正確率、進度完成、課堂節奏）與建議，透過防震盪評分公式自動調整下一堂難度係數。
- **管理員總控台（`/admin`）**
  - 全講師與全體班級進度總覽、平均難度與低檔／下降預警。
  - **直接調整與覆寫**：手動調整班級單元、已完成頁數、強制覆寫難度係數（保留審計紀錄）與撰寫備課批示。
  - **教材庫檢視**：檢視單元與每頁板書的難度區間設定（內建《五上9 多位數乘除技巧》19 頁完整板書）。

## PDF 樣式規格與升級

完整保留原規格包「A4 直式黑白印刷三色粉筆雙重編碼（純黑實線＝白粉筆、灰底虛線＝黃粉筆重點、雙實線框＝紅粉筆標記）」與上下雙層結構，並新增：
1. 可開關的**封面備課總覽頁**（含目標難度、時段目錄、上堂備註與管理員指示）
2. 頁眉**題型難度層級標籤**與防擁擠緊湊圖例
3. **中場休息視覺分隔條**與**節奏應變提示**
4. **Playwright 併發安全渲染**與精準頁碼（`第 X / N 頁`）

## 快速啟動

```bash
chmod +x start.sh
./start.sh
```

- 前端介面：`http://localhost:3000`
- 後端 API 文件：`http://localhost:8000/docs`
